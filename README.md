# React Pizza

Учебный интернет-магазин пиццы на React.

## Что есть в проекте

- каталог пиццы;
- поиск;
- фильтрация по категориям;
- сортировка;
- пагинация;
- корзина;
- страница отдельной пиццы;
- локальные изображения пицц;
- деплой на GitHub Pages.

## Стек

- React
- TypeScript
- Redux Toolkit
- React Router
- SCSS Modules
- Axios
- Create React App

## Запуск

npm install
npm start

## Сборка

npm run build

## Деплой

npm run deploy
